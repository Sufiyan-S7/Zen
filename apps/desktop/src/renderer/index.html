CONFIRMATION REQUIRED

Import documents

Select text documents through Windows. Zen previews their names, types, and sizes before it reads and stores local searchable text. PDF text extraction is not available yet, so PDFs are safely declined.

Supported now: TXT, MD, CSV, and JSON up to 20 MiB each. No folder scanning or automatic import.

YOUR APPROVED APPS

Choose what Zen may open

Select a Windows application. Zen shows its exact path before saving your approval, asks again every time before launching it, and lets you remove approval at any time.

For a Chrome, Edge, Brave, Opera, or Vivaldi web app, name it, enter its HTTPS address, then choose its browser launcher. Zen stores that fixed name, browser, and address only.

Only applications you choose are listed here.

CONFIRMATION REQUIRED

Open a website

Paste an HTTPS address. Zen validates the address format, shows the normalized destination, and waits for your approval before opening your default browser. A website may still return a 404 or sign-in page.

Only HTTPS websites are accepted. Nothing opens until you confirm.

LOCAL FILE SEARCH

Enter a file-name search term, choose a folder, and confirm. Zen reads names and paths in that folder only. It does not read file contents or change anything.

Nothing is searched until you choose a folder and confirm.
