# Zen Four-Week Roadmap

## Week 1 — Foundation and conversation

- Establish the desktop app, design system, logging, and settings.
- Install Ollama and connect a local text chat.
- Add local conversation persistence.
- Add an initial permission-prompt component.

**Done when:** Zen opens, chats locally, and saves a conversation on the PC.

## Week 2 — Safe computer control

- Build the tool registry and activity log.
- Open approved applications and websites.
- Add file search limited to user-selected folders.
- Implement action previews and confirmations.

**Done when:** Zen reliably performs a few approved desktop tasks.

## Week 3 — Personal memory and documents

- Add editable preferences and long-term memory.
- Index user-selected text and PDF documents.
- Add semantic search and document question answering.
- Add custom commands.

**Done when:** Zen can find approved information and remember chosen preferences.

## Week 4 — Workflows and release

- Add simple multi-step workflows.
- Improve error handling, settings, and accessibility.
- Add automated tests for permissions and tools.
- Package a Windows build and record a demo.

**Done when:** a safe, coherent local MVP can be installed and demonstrated.
